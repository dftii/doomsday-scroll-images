# doomsday-scroll-images

Landing page fan-made de **Vengadores: Doomsday** (en cines el 18 de diciembre de 2026), con animación de cartas en órbita al hacer scroll.

## Estructura

- **Portada**: imagen de presentación a pantalla completa con título y fecha.
- **Historia**: 4 capítulos; cada imagen llega por el arco, se expande a pantalla completa y muestra su texto.
- **Bandos**: marquesina con los equipos que se enfrentan a Doom.
- **Cuenta atrás** en directo hasta el estreno.

## Cómo abrirlo

Abre `index.html` en el navegador (necesita conexión a internet para cargar GSAP, Lenis y las fuentes).
No separes `index.html` de la carpeta `public/`, que contiene las imágenes.

## Tecnología

- [GSAP](https://gsap.com/) + ScrollTrigger
- [Lenis](https://lenis.darkroom.engineering/) (scroll suave)
- Animación basada en ORBITS-CARDS
